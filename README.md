[Анализ бизнес-показателей и причин убытков в мобильном приложении](https://github.com/kitomakito/yandex_practicum_projects/tree/6a765632037ad0adc2ec8435d60d5a3eeaf5fd5b/%D0%90%D0%BD%D0%B0%D0%BB%D0%B8%D0%B7%20%D0%B1%D0%B8%D0%B7%D0%BD%D0%B5%D1%81-%D0%BF%D0%BE%D0%BA%D0%B0%D0%B7%D0%B0%D1%82%D0%B5%D0%BB%D0%B5%D0%B9%20%20%D0%B2%20%D1%80%D0%B0%D0%B7%D0%B2%D0%BB%D0%B5%D0%BA%D0%B0%D1%82%D0%B5%D0%BB%D1%8C%D0%BD%D0%BE%D0%BC%20%D0%BF%D1%80%D0%B8%D0%BB%D0%BE%D0%B6%D0%B5%D0%BD%D0%B8%D0%B8)
* **Цель:** Разобраться в причинах убытков и помочь компании выйти в плюс.
* **Что сделано:** Проведен исследовательский анализ данных. **Рассчитаны конверсия, использован когортный анализ: LTV, CAC, Retention rate, DAU, WAU, MAU**. Даны рекомендации.
* **Итог:** Выявлена комплексная проблема, связанная с распределением бюджетов на рекламу без анализа и оценки расходов после запуска (ROI по США не пересек уровень окупаемости спустя первые 2 недели). Самые высокие косты ушли на каналы которые показали в т.ч. и наихудшее удержание. Маркетинг сделал ставку на привлечение пользователей iOS из США через TipTop, но она не сыграла.
Было рекомендовано: остановить использование убыточных AdNonSense для европейского рынка и FaceBoom для американского. Выбрать для привлечения пользователей альтернативные рекламные каналы: lambdaMediaAds для европейского рынка и RocketSuperAds для американского (TipTop был явно переоценён мркетологми).
* **Стек:** Python, Pandas, Matplotlib, Seaborn,когортный анализ, продуктовые метрики, юнит-экономика

#### 2. [A/B-test изменений, связанных с внедрением улучшенной рекомендательной системы](https://github.com/kitomakito/yandex_practicum_projects/tree/7460b5eb038b1bfd7c91418104e1f7d591c1f8b3/ab_test)
* **Цель:** Провести оценку результатов A/B-теста и удостоверится в корректности его проведения.
* **Что сделано:** проверка проведенного A/B-теста на соответствие ТЗ, оценка результатов, EDA, событийная аналитика (влияние на конверсию в воронке событий, влияние на количество событий на пользователя в т.ч. за период), проверка статистической значимости различий между этапами воронки событий в контрольной и новой платежной воронке (z-тест, alpha = 0,05, коррекция по методу Шидака из-за множественных тестов)
* **Итог:** Качество проведённого теста оказалось не высоким, с серьезным перекосом в сторону контрольной группы, условия ТЗ не были выполнены. Эксперимент не привел к улучшению заявленных метрик не менее чем на 10%. Проведенная оценка результаов АБ тестирования и проверка статистической значимость с помощью z-теста (с поправкой на три теста для уменьшения FWER) показала **провал эксперимента**. Различия между контрольной(без изменений) и экпериментальной (пользователи пробовали улучшенную рекомендательную систему) группами на этапах "Корзина" и "Покупка" не являются статистически значимыми, на этапе "Страница товара" результат в экспериментальной группе показал статистически значимое снижение на 9%.
* **Стек:** Python, Pandas, Plotly, Seaborn, Matplotlib, визуализация данных, проверка статистических гипотез, продуктовые метрики, событийная аналитика.

#### 3. [Анализ  закономерностей, определяющих успешность продаж интернет-магазина](https://github.com/kitomakito/yandex_practicum_projects/tree/7460b5eb038b1bfd7c91418104e1f7d591c1f8b3/%D0%98%D1%81%D1%81%D0%BB%D0%B5%D0%B4%D0%BE%D0%B2%D0%B0%D0%BD%D0%B8%D0%B5%20%D1%80%D1%8B%D0%BD%D0%BA%D0%B0%20%D0%B8%D0%B3%D1%80)
* **Цель:** Используя исторические данные о продажах компьютерных игр, выявить закономерности, определяющие успешность продаж. 
* **Что сделано:** Проведена предобработка данных, исследовательский анализ данных. Выбран актуальный период для анализа. Определен жизненный цикл продаж игр в зависимости от платформы, для которой она сделана И составлен прогноз на продажи следующего года. Визуализированы параметры, влияющие на продажи, построены графики корреляции, heatmap, boxplot, определены топ-5 платформ, жанров для каждого региона, составлен портреты пользователей. Проверены 2 гипотезы с использованием критерия Стьюдента для независимых выборок.
* **Итог:** Выявлены параметры, определяющие успешность продаж игры в разных регионах мира и параметры, на которые можно не обращать внимания. На основании этого подготовлен отчет для планирования рекламных кампаний. Определены наиболее привлекательные платформы с окном актуальности игр в 1-3 года. 
* **Стек:** Python, Pandas, NumPy, Matplotlib, Seaborn, исследовательский анализ данных (EDA), описательная статистика, предобработка данных, проверка статистических гипотез

* #### 4. [Разведочный анализ (EDA) объявлений о продаже квартир](https://github.com/kitomakito/yandex_practicum_projects/tree/7460b5eb038b1bfd7c91418104e1f7d591c1f8b3/%D0%90%D0%BD%D0%B0%D0%BB%D0%B8%D0%B7%20%D1%80%D1%8B%D0%BD%D0%BA%D0%B0%20%D0%BD%D0%B5%D0%B4%D0%B2%D0%B8%D0%B6%D0%B8%D0%BC%D0%BE%D1%81%D1%82%D0%B8%20%D0%A1%D0%B0%D0%BD%D0%BA%D1%82-%D0%9F%D0%B5%D1%82%D0%B5%D1%80%D0%B1%D1%83%D1%80%D0%B3%D0%B0)
* **Цель:** Определить рыночную стоимость объектов недвижимости и типичные параметры квартир в целях построения автоматизированной системы по отслеживанию аномалий и мошеннической деятельности.
* **Что сделано:** На основе данных определена рыночная стоимость объектов недвижимости по типам, определены параметры влияющие на стоимость объекта. Проведена предобработка и обогащение данных. Визуализация параметров с помощью гистограмм, боксплот, диаграмм рассеивания. Анализ зависимостей.
* **Итог:** Данные подготовлены для дальнейшего анализа: очищены от выбросов, аномальных и недостоверных значений. Рассчитана средняя скорость продажи квартиры, определены параметры с наибольшим влиянием на стоимость объекта (сильная зависимость от размера общей площади, средняя зависимость от размера жилой площади, размера площади кухни), проведен анализ зависимости цены квадратного метра от удаленности от центра города. Выявлена нелинейная корреляция между ценой и типом этажа (первый/последний/другой). 
* **Стек:** Python, Pandas, Matplotlib, визуализация данных, исследовательский анализ данных (EDA), предобработка данных.
