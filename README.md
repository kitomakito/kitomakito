### 🚀 Мои ключевые проекты


#### 1. [Анализ убытков в мобильном приложении](ссылка_на_ваш_репозиторий_1)
* **Цель:** Разобраться в причинах убытков и помочь компании выйти в плюс.
* **Что сделано:** Проведен исследовательский анализ данных. Рассчитаны конверсия, использован когортный анализ: LTV, CAC, Retention rate, DAU, WAU, MAU. Использованы уже написанные ранее функции расчёта метрик. Даны рекомендации.
* **Итог:** Выявлена комплексная проблема, связанная с распределением бюджетов на рекламу без оглядки на особенности рынков Европы и США и выбором дорогих и неэффективных каналов привлечения, а также с неверном выбором целевого рынка. Для отдела маркетинга сформированы рекомендации по корректировке рекламных расходов и приоритизации рекламных источников.
* **Стек:** Python, Pandas, Matplotlib, Seaborn,когортный анализ, продуктовые метрики, юнит-экономика

#### 2. [Разведочный анализ (EDA) объявлений о продаже квартир](https://github.com/kitomakito/yandex_practicum_projects/tree/aabdd930732babee8336405b104a6b58d5addc77/%D0%90%D0%BD%D0%B0%D0%BB%D0%B8%D0%B7%20%D1%80%D1%8B%D0%BD%D0%BA%D0%B0%20%D0%BD%D0%B5%D0%B4%D0%B2%D0%B8%D0%B6%D0%B8%D0%BC%D0%BE%D1%81%D1%82%D0%B8%20%D0%A1%D0%B0%D0%BD%D0%BA%D1%82-%D0%9F%D0%B5%D1%82%D0%B5%D1%80%D0%B1%D1%83%D1%80%D0%B3%D0%B0)
* **Цель:** Определить рыночную стоимость объектов недвижимости и типичные параметры квартир в целях построения автоматизированной системы по отслеживанию аномалий и мошеннической деятельности.
* **Что сделано:** На основе данных сервиса Яндекс.Недвижимость определена рыночная стоимость объектов недвижимости разного типа, типичные параметры квартир, в зависимости от удаленности от центра. Проведена предобработка и обогащение данных. Визуализация параметров с помощью гистограмм, боксплот, диаграмм рассеивания. Анализ зависимостей.
* **Итог:** Данные подготовлены для дальнейшего анализа: очищены от выбросов, аномальных и недостоверных значений. Рассчитана средняя скорость продажи квартиры, определены параметры с наибольшим влиянием на стоимость объекта (сильная зависимость от размера общей площади, средняя зависимость от размера жилой площади, размера площади кухни), проведен анализ зависимости цены квадратного метра от удаленности от центра города. Выявлена нелинейная корреляция между ценой и типом этажа (первый/последний/другой). 
* **Стек:** Python, Pandas, Matplotlib, визуализация данных, исследовательский анализ данных (EDA), предобработка данных.

#### 3. [Анализ  закономерностей, определяющих успешность продаж интернет-магазина](https://github.com/kitomakito/yandex_practicum_projects/tree/d682df03f80038e053c5f21d0efbdb46043b3e21/%D0%98%D1%81%D1%81%D0%BB%D0%B5%D0%B4%D0%BE%D0%B2%D0%B0%D0%BD%D0%B8%D0%B5%20%D1%80%D1%8B%D0%BD%D0%BA%D0%B0%20%D0%B8%D0%B3%D1%80)
* **Цель:** Используя исторические данные о продажах компьютерных игр, оценки пользователей и экспертов, жанры и платформы, выявить закономерности, определяющие успешность. 
* **Что сделано:** Проведена предобработка данных, исследовательский анализ данных. Выбран актуальный период для анализа. Определен жизненный цикл продаж игр в зависимости от платформы, для которой она сделана И составлен прогноз на продажи следующего года. Визуализированы параметры, влияющие на продажи, построены графики корреляции, heatmap, boxplot, определены топ-5 платформ, жанров для каждого региона, составлен портреты пользователей. Проверены 2 гипотезы с использованием критерия Стьюдента для независимых выборок.
* **Итог:** Выявлены параметры, определяющие успешность продаж игры в разных регионах мира и параметры, на которые можно не обращать внимания. На основании этого подготовлен отчет для планирования рекламных кампаний. Определены наиболее привлекательные платформы с окном актуальности игр в 1-3 года. 
* **Стек:** Python, Pandas, NumPy, Matplotlib, Seaborn, исследовательский анализ данных (EDA), описательная статистика, предобработка данных, проверка статистических гипотез

 #### 4. [A/B-test изменений, связанных с внедрением улучшенной рекомендательной системы](https://github.com/kitomakito/yandex_practicum_projects/tree/d682df03f80038e053c5f21d0efbdb46043b3e21/ab_test)
* **Цель:** Провести оценку результатов A/B-теста и удостоверится в корректности его проведения.
* **Итог:** Качество проведённого теста оказалось не высоким, с серьезным перекосом в сторону контрольной группы, условия ТЗ не были выполнены. 
Также был проведен EDA + событийная аналитика, изменение конверсии пользователей в воронке на разных этапах (логин/карточка товара/корзина/покупка). 
Проведена оценка результаов АБ тестирования и проверка статистической значимость с помощью z-теста (с поправкой на три теста для уменьшения FWER  aka групповой вероятности ошибки первого рода по методу Шидака)
* **Стек:** Python, Pandas, Plotly, Seaborn, Matplotlib, визуализация данных, проверка статистических гипотез, продуктовые метрики, событийная аналитика.
